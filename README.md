# ⛽ Fuel Calculator

Aplicativo Android que calcula quanto você vai gastar de combustível em uma viagem.

## 📱 Sobre o projeto

O usuário informa o preço do combustível, o consumo do veículo e a distância. O app mostra o custo total da viagem e um resumo dos dados digitados.

## ✨ Funcionalidades

- Entrada do preço do combustível por litro
- Entrada do consumo do veículo, em km por litro
- Entrada da distância da viagem, em km
- Cálculo do custo total
- Revisão dos dados inseridos
- Opção de calcular novamente


## 🗺️ Telas

| Ordem | Activity | Função |
| --- | --- | --- |
| 1 | `MainActivity` | Tela inicial |
| 2 | `PrecoCombustivelActivity` | Preço do combustível |
| 3 | `ConsumoPorLitroActivity` | Consumo do veículo |
| 4 | `DistanciaActivity` | Distância e cálculo |
| 5 | `ResultadoActivity` | Custo total e revisão dos dados |

## 🛠️ Tecnologias

- Kotlin
- Layouts em XML
- AndroidX AppCompat e ConstraintLayout
- Material Components
- Gradle com Kotlin DSL


## 🚀 Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/Lira95/fuel-calculator.git
   ```

2. Abra a pasta no Android Studio.
3. Aguarde a sincronização do Gradle.
4. Selecione um dispositivo ou emulador e clique em **Run**.
